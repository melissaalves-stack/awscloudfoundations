# Mapa: módulos × domínios das provas

Este repositório é organizado por **aprendizado**, não por prova. Esta tabela faz a ponte quando você quiser estudar mirando um domínio específico.

| D1 — Fundamentos de IA e ML | 20% | 12 |

| D5 — Segurança, Conformidade e Governança | 14% | 02, 09, 15 |

## Ordem sugerida

Faça o **CLF-C02 primeiro**. O exame de IA assume que você já entende IAM, S3, VPC e o modelo de responsabilidade compartilhada — sem isso você estuda a mesma coisa duas vezes.

- **Módulos 00–10** → pronto para o CLF-C02
- **Módulos 11–15** → pronto para o AIF-C01

- https://aws.amazon.com/free — Free Tier
