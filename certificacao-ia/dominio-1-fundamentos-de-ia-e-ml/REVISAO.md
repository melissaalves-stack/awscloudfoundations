## ⚡ Em 30 segundos

- IA ⊃ Machine Learning ⊃ Deep Learning.
- Três tipos de aprendizado: supervisionado, não supervisionado e por reforço.
- Ciclo de vida: dados → treino → avaliação → implantação → monitoramento.

## 🎯 Se a questão fala em… pense em…

| Se a questão fala em… | Pense em… |
|:--|:--|
| Exemplos rotulados (entrada → resposta) | **Aprendizado supervisionado** |
| Agrupar clientes sem rótulos | **Não supervisionado (clustering)** |
| Aprender por recompensa | **Aprendizado por reforço** |
| Prever um número (preço, demanda) | **Regressão** |
| Prever uma categoria (spam ou não) | **Classificação** |
| Usar o modelo pronto para responder | **Inferência** |
| Ótimo no treino, ruim em dados novos | **Overfitting** |
| Ruim até no treino | **Underfitting** |
| Modelo piora com o tempo | **Drift — monitore e retreine** |

## ⚠️ Pegadinhas

- Treino ≠ inferência: treino ajusta o modelo, inferência usa.
- Mais dados não corrigem dados enviesados.
