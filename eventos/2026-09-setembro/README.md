## 🧰 O Arsenal AWS

**Serviços AWS por categoria — Domínio 3 · Tecnologia e Serviços (CLF-C02)**

| Campo | Detalhe |
|:--|:--|
| 📅 **Data** | 24 de setembro de 2026 |
| 🎤 **Facilitadoras** | Melissa (Parte 1) · Julia (Parte 2) |
| 🎯 **Domínio da prova** | Domínio 3 · Tecnologia e Serviços — 34% do CLF-C02, o maior peso |
| 📂 **Materiais** | [Slides teóricos (PDF)](./slides/arsenal-aws-slides-teoricos.pdf) |

O domínio que mais pesa na prova pede que você reconheça **qual serviço resolve qual problema**. Percorremos o "arsenal" da AWS por categoria — sempre com a pergunta de prova na cabeça: *para esse cenário, qual serviço eu escolho?*

### 🎯 O que vimos

**Parte 1 · Melissa**

- **Computação** — EC2 e famílias de instância, Auto Scaling (mín./desejado/máx.), Lambda, ECS, Fargate, Elastic Beanstalk e Lightsail
- **Armazenamento** — S3 e suas classes (Standard → Deep Archive), EBS (bloco), EFS (arquivo) e Storage Gateway (híbrido)
- **Bancos de dados** — RDS e Aurora (relacional), DynamoDB (NoSQL), ElastiCache (cache) e Redshift (data warehouse)

**Parte 2 · Julia**

- **Rede e entrega** — VPC (sub-redes pública e privada, Internet e NAT Gateway), Security Groups vs. NACLs, Route 53, CloudFront, ELB, API Gateway e Direct Connect
- **Monitoramento** — CloudWatch, CloudTrail e EventBridge
- **Mensageria** — SNS (pub/sub), SQS (fila) e Step Functions
- **Infra como código e gestão** — CloudFormation e Systems Manager
- **Boas práticas** — Trusted Advisor e AWS Config

> [!TIP]
> **Atalhos de prova:** "sem gerenciar servidor" → Lambda ou Fargate · "suba o código e pronto" → Beanstalk · "simples e barato" → Lightsail · CloudWatch = métricas · CloudTrail = quem fez o quê.

### 🧠 Para levar

| Se a questão fala em… | Pense em… |
|:--|:--|
| Servidor virtual com controle do SO | EC2 |
| Rodar código por evento, pagando por execução | Lambda |
| Armazenar objetos com 11 noves de durabilidade | S3 |
| Disco para uma instância EC2 | EBS |
| Arquivos compartilhados entre instâncias | EFS |
| NoSQL serverless em milissegundos | DynamoDB |
| Análise de petabytes (OLAP) | Redshift |
| Desacoplar serviços com fila | SQS |
| Descrever a infraestrutura em YAML/JSON | CloudFormation |
