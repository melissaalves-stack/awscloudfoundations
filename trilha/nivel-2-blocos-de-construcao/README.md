# 🔵 Nível 2 · Os Blocos de Construção

> **Tempo total estimado:** ~18h · **Pré-requisito:** concluir o [Nível 1](../nivel-1-fundamentos-de-nuvem/README.md)

Agora que você entende **o que** é a nuvem, vamos conhecer as peças com que se constrói qualquer sistema: computação, armazenamento, redes e bancos de dados. São os "tijolos" de todo projeto na AWS. 🧱

| 06 | [Bancos de dados gerenciados](./06-bancos-de-dados.md) | 4h |

## 🎯 Ao final deste nível você vai...
- Escolher o serviço de computação certo para cada situação.
- Entender os três tipos de armazenamento e quando usar cada um.
- Compreender como funciona uma rede na nuvem (VPC, DNS, CDN).
- Saber diferenciar bancos relacionais e NoSQL gerenciados.
