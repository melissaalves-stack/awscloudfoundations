## ⚡ Em 30 segundos

- Modelos de fundação são grandes, pré-treinados e adaptáveis a muitas tarefas.
- LLMs processam tokens; embeddings representam significado como vetores.
- O prompt é a principal alavanca: contexto, exemplos e formato da resposta.

## 🎯 Se a questão fala em… pense em…

| Se a questão fala em… | Pense em… |
|:--|:--|
| Modelo grande e reutilizável | **Modelo de fundação** |
| Unidade de texto e de cobrança | **Token** |
| Vetor que representa significado | **Embedding** |
| Resposta convincente, mas falsa | **Alucinação** |
| Respostas mais criativas / variadas | **Temperatura alta** |
| Respostas mais previsíveis | **Temperatura baixa** |
| Dar exemplos no prompt | **Few-shot** |
| Pedir raciocínio passo a passo | **Chain-of-thought** |
| Quanto texto o modelo "enxerga" | **Janela de contexto** |

## ⚠️ Pegadinhas

- Temperatura não muda o conhecimento do modelo, só a aleatoriedade.
- Zero-shot = sem exemplos; few-shot = com alguns exemplos.
