# 3️⃣ Domínio 3 · Tecnologia e Serviços

> **Peso na prova:** 34% · **Tempo total estimado:** ~16h · **Pré-requisito:** Domínios 1 e 2

Este é o **maior domínio da prova**. Aqui você conhece os serviços centrais da AWS na prática: como rodar aplicações (computação), guardar dados (armazenamento), conectar tudo (redes), persistir informações (bancos de dados) e manter tudo escalável e disponível.

## 🎯 Ao final deste domínio você vai...

- Saber as formas de interagir com a AWS (Console, CLI, SDK, IaC).
- Escolher o serviço de **computação** certo (EC2, Lambda, containers).
- Diferenciar os tipos de **armazenamento** (objetos, blocos, arquivos).
- Entender **VPC**, sub-redes, DNS (Route 53) e CDN (CloudFront).
- Escolher o **banco de dados** adequado (relacional x não relacional).
- Explicar **Elastic Load Balancing** e **Auto Scaling** e como garantem alta disponibilidade.
