# 🔵 Nível 2 · Os Blocos de Construção

> **Tempo total estimado:** ~18h · **Pré-requisito:** concluir o [Nível 1](../nivel-1-fundamentos-de-nuvem/README.md)

Agora que você entende **o que** é a nuvem, vamos conhecer as peças com que se constrói qualquer sistema: computação, armazenamento, redes e bancos de dados. São os "tijolos" de todo projeto na AWS. 🧱

> [!NOTE]
> 📅 **No cronograma da Liga:** este nível é o coração do **Evento 2 · O Arsenal** (Set/2026), o encontro dedicado aos serviços core, e o módulo de Redes é revisitado no **Bootcamp de Revisão I** (Mar/2027). Cobre o maior domínio da prova: **CLF-C02 D3 · Cloud Technology & Services (34%)**.

## 🎯 Ao final deste nível você vai...
- Escolher o serviço de computação certo para cada situação (EC2, containers, serverless, Beanstalk).
- Entender os tipos de armazenamento (objetos, blocos, arquivos) e a durabilidade do S3.
- Compreender como funciona uma rede na nuvem (VPC, sub-redes, Security Groups vs NACLs, DNS, CDN).
- Saber diferenciar bancos relacionais e NoSQL, e Multi-AZ de Read Replicas.
