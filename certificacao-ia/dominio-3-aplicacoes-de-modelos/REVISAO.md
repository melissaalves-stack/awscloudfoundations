## ⚡ Em 30 segundos

- Bedrock dá acesso a modelos de fundação por API; SageMaker é para construir e treinar.
- Para usar dados próprios: prompt → RAG → fine-tuning, em ordem de custo.
- Agentes encadeiam passos e ferramentas; avalie modelos com métricas e humanos.

## 🎯 Se a questão fala em… pense em…

| Se a questão fala em… | Pense em… |
|:--|:--|
| Usar modelos prontos por API, serverless | **Amazon Bedrock** |
| Construir, treinar e implantar ML próprio | **SageMaker** |
| Responder com documentos da empresa, sem retreinar | **RAG** |
| Banco para busca por similaridade | **Vector store / OpenSearch** |
| Especializar o modelo com dados próprios | **Fine-tuning** |
| Executar tarefas em várias etapas | **Agentes (Bedrock Agents)** |
| Filtrar conteúdo indesejado | **Guardrails** |
| Transcrever áudio | **Amazon Transcribe** |
| Extrair texto de documentos | **Amazon Textract** |
| Analisar imagens | **Amazon Rekognition** |

## ⚠️ Pegadinhas

- RAG não altera o modelo; fine-tuning altera.
- Bedrock = consumir modelos; SageMaker = criar modelos.
