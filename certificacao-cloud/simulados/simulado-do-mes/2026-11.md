## Como participar

1. Separe **30 minutos** sem interrupção e inicie o cronômetro.

3. Pare o cronômetro e **[envie suas respostas](https://github.com/melissaalves-stack/awscloudfoundations/issues/new?template=simulado-do-mes.yml)** — 20 letras em sequência, ex.: `ABCDABCDABCDABCDABCD`.

**1.** Um usuário implanta uma instância de banco de dados do Amazon RDS em várias zonas de disponibilidade. Essa estratégia envolve qual pilar do AWS Well-Architected Framework?

- A) Eficiência de desempenho
- B) Otimização de custos
- C) Confiabilidade
- D) Segurança

**2.** Qual serviço da AWS permite que clientes comprem capacidade não utilizada do Amazon EC2 a uma taxa com desconto?

- A) Spot Instances
- B) Instâncias sob demanda
- C) Instâncias reservadas
- D) Instâncias dedicadas

**3.** Um usuário precisa descobrir, classificar e proteger automaticamente dados sigilosos armazenados no Amazon S3. Qual serviço da AWS atende a esses requisitos?

- A) Amazon GuardDuty
- B) Amazon Macie
- C) Amazon Inspector
- D) AWS Secrets Manager

**4.** Para obter acesso programático à AWS, um usuário já tem uma ID de chave de acesso. O que mais é necessário?

- A) Uma chave de acesso secreta
- B) Uma ID de usuário
- C) Uma chave secundária
- D) Uma chave privada

**5.** Uma empresa necessita de um banco de dados relacional para gerenciar previsões de vendas de filiais. Qual serviço da AWS atende a esse requisito?

- A) Amazon Elastic Block Store (Amazon EBS)
- B) Amazon Aurora
- C) Amazon DynamoDB
- D) AWS Global Accelerator

**6.** Cada departamento de uma empresa tem sua própria conta independente da AWS e solução de pagamento. A empresa precisa centralizar a governança e consolidar pagamentos. Qual solução atende a esses objetivos?

- A) Criar uma organização no AWS Organizations e consolidar todas as contas para pagamento
- B) Usar o AWS Systems Manager OpsCenter
- C) Configurar o Centro de identidade do IAM
- D) Usar a página AWS Cost and Usage Reports

**7.** Uma empresa tem um servidor on-premises Linux com banco de dados Oracle e quer migrar para uma instância do Amazon EC2. Qual serviço usar?

- A) AWS Database Migration Service (AWS DMS)
- B) AWS Schema Conversion Tool (AWS SCT)
- C) AWS Application Migration Service (AWS MGN)
- D) AWS Outposts

**8.** Qual das opções descreve corretamente o Amazon S3?

- A) Um armazenamento de objetos durável
- B) Um sistema de arquivos de rede compartilhado entre instâncias
- C) Um disco de blocos para uma instância EC2
- D) Um banco de dados relacional gerenciado

**9.** Uma equipe de desenvolvimento precisa de uma solução que envie um alerta para toda a equipe quando um teste de garantia de qualidade falhar. Qual serviço da AWS usar?

- A) Amazon Simple Notification Service (Amazon SNS)
- B) Amazon Simple Queue Service (Amazon SQS)
- C) Amazon EventBridge
- D) Amazon Connect

**10.** Qual serviço da AWS identifica grupos de segurança que permitem acesso irrestrito aos recursos da AWS?

- A) AWS Trusted Advisor
- B) AWS Identity and Access Management (IAM)
- C) AWS CloudTrail
- D) Amazon CloudWatch

**11.** Uma empresa quer criar um aplicativo de aprendizagem em que os alunos possam ouvir o texto sendo lido em voz alta. Qual serviço de machine learning da AWS atende a esse requisito?

- A) Amazon Translate
- B) Amazon Polly
- C) Amazon Transcribe
- D) Amazon Textract

**12.** Uma empresa global quer reduzir a latência para usuários ao redor do mundo, usando locais de borda para cache de conteúdo. Qual serviço da AWS atende a esse requisito?

- A) AWS Direct Connect
- B) Amazon Route 53
- C) Amazon CloudFront
- D) Elastic Load Balancing

**13.** Após ultrapassar o nível gratuito, o AWS Lambda cobra com base em qual fator, além do número de solicitações?

- A) A linguagem de programação usada
- B) O tempo de execução da função do Lambda
- C) O número de versões de uma função do Lambda
- D) O número total de funções na conta

**14.** De acordo com o modelo de responsabilidade compartilhada da AWS, qual tarefa é de responsabilidade do CLIENTE?

- A) Instalar patches nas instâncias do Amazon RDS
- B) Corrigir o sistema operacional que as funções do Lambda usam
- C) Configurar os usuários do IAM com o princípio de menor privilégio
- D) Controlar o acesso físico aos data centers da AWS

**15.** Qual é o plano MÍNIMO do AWS Support que fornece suporte técnico por chamadas telefônicas?

- A) Developer
- B) Basic
- C) Business
- D) Enterprise

**16.** Uma empresa precisa de uma conexão criptografada entre seus servidores on-premises e a AWS, usando a conexão de internet existente. Qual solução atende a esse requisito?

- A) AWS Site-to-Site VPN
- B) Amazon CloudFront
- C) Amazon Connect
- D) AWS Direct Connect

**17.** Uma empresa implantou instâncias do Amazon EC2 em várias zonas de disponibilidade. Além de aumentar a disponibilidade, qual outro benefício essa arquitetura oferece?

- A) Permite atender usuários entre regiões com baixa latência
- B) Aumenta automaticamente a carga do aplicativo
- C) Elimina o risco de um único ponto de falha
- D) Reduz automaticamente os custos operacionais

**18.** Uma empresa quer monitorar a utilização de CPU de instâncias do Amazon EC2 e receber alertas quando ultrapassar 80%. Qual serviço da AWS usar?

- A) Amazon CloudWatch
- B) AWS CloudTrail
- C) AWS Trusted Advisor
- D) AWS Config

**19.** Uma empresa precisa garantir que os recursos da AWS sejam sempre provisionados conforme as políticas internas, detectando automaticamente recursos não conformes. Qual serviço usar?

- A) Amazon GuardDuty
- B) AWS Config
- C) Amazon Inspector
- D) AWS CloudTrail

**20.** Qual serviço da AWS permite descrever toda a infraestrutura em arquivos YAML ou JSON e recriar o ambiente de forma repetível e automatizada?

- A) AWS CloudFormation
- B) AWS Elastic Beanstalk
- C) AWS Systems Manager
- D) AWS OpsWorks
